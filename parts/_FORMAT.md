# Формат файла истории (один объект, без обёртки в массив)

Файл должен быть **ровно одним литералом объекта**, без `const`, без `;` в конце, без комментариев сверху (можно оставить, но не обязательно).

```js
{
emoji:'🐶',title:'The Little Dog',start:'s1',
segs:{
 s1:{text:`...текст на английском, можно несколько абзацев через пустую строку...`,
  choices:[{t:'Кнопка выбора на русском',n:'s2'},{t:'Другой вариант',n:'s3'}]},
 s2:{text:`...`, choices:[{t:'...',n:'s4'}]},
 s3:{text:`...`, ending:true},
 ...
},
quiz:[
 {q:'Question in English?',o:['Option1','Option2','Option3'],a:0},
 {q:'...',o:['...','...','...'],a:2}
]
}
```

## Правила

1. `text` — ВСЕГДА в обратных кавычках (template literal). Внутри может быть перенос строки и абзацы.
2. Кнопки выбора `t` — **на русском языке** (интерфейс русский). `n` — имя сегмента-перехода.
3. Концовка: `ending:true` (без `choices`). У истории должно быть **минимум 2-3 разных концовки**.
4. `start:'s1'` — всегда s1.
5. Каждая история от `start` должна делать все сегменты достижимыми (без «мёртвых» сегментов). Не должно быть ссылок на несуществующие сегменты.
6. Квиз: 5 вопросов, у каждого 3 варианта, `a` — индекс правильного ответа (0,1,2). Вопросы и варианты — на английском, по содержанию истории.
7. Слова считаются как `[A-Za-z']+` по всем `text`.
8. Внутри одинарных кавычек НЕЛЬЗЯ использовать апострофы без экранирования: вместо `cat's` пишите `cat\'s`, либо используйте двойные кавычки `"cat's"`.

## Проверка файла

Из папки проекта:
```
node -e "const fs=require('fs');const raw=fs.readFileSync('<ФАЙЛ>','utf8');const o=eval('['+raw+'][0]');const segs=o.segs||{};let w=0;for(const k in segs)w+=(segs[k].text.match(/[A-Za-z']+/g)||[]).length;const ks=Object.keys(segs);const broken=[];for(const k of ks)for(const c of (segs[k].choices||[]))if(!segs[c.n])broken.push(k+'->'+c.n);const seen=new Set([o.start]);const q=[o.start];while(q.length){const k=q.shift();for(const c of (segs[k].choices||[]))if(!seen.has(c.n)){seen.add(c.n);q.push(c.n);}}console.log('title='+o.title,'segs='+ks.length,'words='+w,'endings='+ks.filter(k=>segs[k].ending).length,'broken='+(broken.join(',')||'нет'),'unreach='+(ks.filter(k=>!seen.has(k)).join(',')||'нет'));"
```

Требуемый результат (для B1): words >= 2900, endings >= 3, broken=нет, unreach=нет.

## Как писать большие файлы (важно!)

Файл может не поместиться в один вызов записи. Работайте кусками:

1. Запишите первую часть через Write в `<ФАЙЛ>.a` (заголовок `{emoji:...segs:{` + первые сегменты).
2. Продолжите через Write в `<ФАЙЛ>.b`, `<ФАЙЛ>.c` и т.д. (сегменты без заголовка; последний кусок закрывает `},\nquiz:[...]\n}`).
3. Склейте: `cat <ФАЙЛ>.a <ФАЙЛ>.b <ФАЙЛ>.c > <ФАЙЛ>` (в Git Bash).
4. Прогоните проверку выше. Если ошибка — поправьте кусок(и) и склейте снова.
