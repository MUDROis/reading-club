# Детская читалка · reading-club

Веб-приложение для чтения английских историй детьми: 21 история на трёх уровнях (A1 ×7, A2 ×7, B1 ×7) с выбором хода событий, озвучкой, квизами и словарём.

**Сайт (GitHub Pages):** ссылка появится после включения Pages.

## Возможности

- Уровни A1 / A2 / B1, список историй с эмодзи;
- Режим чтения: крупный текст, «Предыдущая/Следующая», размер шрифта (A− / A / A+);
- Озвучка (Web Speech API);
- Клик по слову — перевод;
- Выбор хода истории: на каждом шаге минимум 2 варианта, в каждом рассказе минимум 3 точки выбора;
- Квиз в конце (5 вопросов, ответы перемешиваются);
- Словарь сложных слов + «Мои слова» (localStorage);
- Оценка времени чтения.

Интерфейс — русский, тексты историй и кнопки выбора — английские.

## Запуск

Это статический сайт: просто откройте `index.html` (или `app.html`) в браузере — работает без сервера. Можно разместить на любом статическом хостинге.

## Структура

- `index.html` / `app.html` — приложение (одна самодостаточная страница, CSS и JS внутри). `index.html` — копия `app.html` для GitHub Pages.
- `parts/` — исходники 21 истории (по файлу на историю), формат описан в `parts/_FORMAT.md`.
- `_build_app.js` — пересборка `app.html` из `parts/` (запуск: `node _build_app.js`).
- `_validate.js` — проверка историй (битые ссылки, достижимость, квизы).
